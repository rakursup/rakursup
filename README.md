## ✨ О проекте


Локальная стартовая страница на **чистом HTML, CSS и JavaScript** — без фреймворков,
сборок и зависимостей. Просто открой `index.html` или зайди на
[rakursup.github.io](https://rakursup.github.io/). Все данные хранятся в браузере
(localStorage) и никуда не отправляются.

## 🖼️ Свои обои


Фон страницы можно заменить на любое изображение — кнопка **«Обои»** в подвале.

**Как это работает:**
1. Нажми **🖼️ Обои** → выбери картинку на компьютере
2. Дашборд сам сожмёт её до ширины **1920 px** (JPEG, качество 0.7)
3. Если файл больше **2 МБ** — повторит сжатие с качеством 0.5
4. Готово: фон установится и сохранится в браузере

> 💡 Обои хранятся локально в `localStorage`, поэтому на другом устройстве
> их нужно будет установить заново. Слишком большие изображения (> 2 МБ
> после сжатия) не сохранятся — браузер отведёт под них ограниченное место.

## 📦 Импорт и экспорт закладок


Резервное копирование и перенос закладок между устройствами — в формате **JSON**.

### Экспорт (сохранить)
1. Нажми **⬇️ Экспорт** в подвале
2. Скачается файл `dashboard-backup-YYYY-MM-DD.json` со всеми категориями

### Импорт (загрузить)
1. Нажми **⬆️ Импорт** → выбери JSON-файл
2. Дашборд проверит структуру файла
3. После подтверждения текущие закладки **заменятся** импортированными

> ⚠️ Импорт полностью заменяет текущие закладки. Сначала сделай экспорт,
> если хочешь сохранить то, что есть.

**Формат файла** (для ручного редактирования):
```json
[
  {
    "title": "📧 Почта",
    "links": [
      { "name": "Gmail", "url": "https://gmail.com/" }
    ]
  }
]
```


## ✏️ Редактирование блоков


Кнопка-карандаш ✏️ в шапке включает режим редактирования — рамки карточек
станут пунктирными.

В этом режиме доступно:

| Действие | Как |
|---|---| 
| 🔄 Поменять порядок карточек | Перетащи карточку мышкой (drag-and-drop) |
| ➕ Добавить категорию | Кнопка «+ Добавить категорию» |
| 🔗 Добавить ссылку | «+ Добавить ссылку» внутри карточки |
| ❌ Удалить ссылку | Крестик ✕ рядом со ссылкой |
| 🗑️ Удалить категорию | Значок 🗑️ в заголовке карточки | 

📌 В одной категории помещается до 7 ссылок. Чтобы добавить больше —  удали одну из существующих.
Повторный клик по карандашу выключает режим редактирования.
