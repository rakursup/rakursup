## ✨ О проекте

Локальная стартовая страница на **чистом HTML, CSS и JavaScript** — без фреймворков, сборок и зависимостей. Открой `index.html` или зайди на [rakursup.github.io](https://rakursup.github.io/).

Все данные хранятся **только в твоём браузере** (localStorage) и никуда не отправляются.

Сделано в тесном сотрудничестве с https://chat.qwen.ai/ 
В работе принимали участие модели ИИ 🤖 Qwen3.7-Max и 🤖 Qwen3.8-Max-Preview.

## 🔍 Поиск в интернете

Строка поиска в шапке поддерживает **4 поисковика** — выбери нужный в выпадающем списке слева. Выбор запоминается.

- **Яндекс** — по умолчанию
- **Google** — классика
- **DuckDuckGo** — без слежки
- **Shodan** — поиск по IoT-устройствам (для энтузиастов)

Результат открывается в новой вкладке.

## 🖼️ Свои обои

Фон страницы можно заменить на любое изображение — кнопка **«Обои»** в подвале.

**Как это работает:**

1. Нажми **🖼️ Обои** → выбери картинку на компьютере
2. Дашборд сам сожмёт её до ширины **1920 px** (JPEG, качество 0.7)
3. Если файл больше **2 МБ** — повторит сжатие с качеством 0.5
4. Фон установится и сохранится в браузере

> 💡 Обои хранятся локально в `localStorage`, поэтому на другом устройстве их нужно установить заново. Изображения больше 2 МБ после сжатия не сохранятся — браузер отводит под хранилище ограниченное место.

## 📦 Импорт и экспорт закладок

Резервное копирование и перенос закладок между устройствами — в формате **JSON**.

### Экспорт (сохранить)

1. Нажми **⬇️ Экспорт** в подвале
2. Скачается файл `dashboard-backup-YYYY-MM-DD.json` со всеми категориями

### Импорт (загрузить)

1. Нажми **⬆️ Импорт** → выбери JSON-файл
2. Дашборд проверит структуру файла
3. После подтверждения текущие закладки **заменятся** импортированными

> ⚠️ Импорт полностью заменяет текущие закладки. Сначала сделай экспорт, если хочешь сохранить то, что есть.

**Формат файла** (для ручного редактирования):

```json
[
  {
    "title": "📧 Почта",
    "links": [
      { "name": "Gmail", "url": "https://gmail.com/" }
    ]
  }
]
```

## ✏️ Редактирование блоков

Кнопка-карандаш **✏️** в шапке включает режим редактирования — рамки карточек станут пунктирными.

В этом режиме доступно:

| Действие | Как |
|---|---|
| 🔄 Поменять порядок карточек | Перетащи карточку мышкой (drag-and-drop) |
| ➕ Добавить категорию | Кнопка **«+ Добавить категорию»** |
| 🔗 Добавить ссылку | **«+ Добавить ссылку»** внутри карточки |
| ❌ Удалить ссылку | Крестик **✕** рядом со ссылкой |
| 🗑️ Удалить категорию | Значок **🗑️** в заголовке карточки |

> 📌 В одной категории помещается до **7 ссылок**. Чтобы добавить больше — удали одну из существующих.

Повторный клик по карандашу выключает режим редактирования.

## 🎨 Темы и акценты

- **Светлая / тёмная тема** — кнопка 🌙/☀️ в шапке. При первом запуске определяется по системным настройкам.
- **4 акцентных цвета** — оранжевый, синий, розовый, бирюзовый. Меняют кнопки, ссылки, заголовки и прогресс-бары. Выбор сохраняется.

## 📁 Структура проекта

```text
├── index.html        # разметка страницы
├── style.css         # стили, темы, адаптив
├── favicon.svg       # иконка (фирменный градиент)

```

> 📚 Порядок загрузки скриптов важен: `utils.js` → `app.js` → виджеты.

## 🛠️ Технологии

- **HTML5** — семантическая разметка, доступность (ARIA)
- **CSS3** — custom properties, grid, адаптив, светлая/тёмная тема
- **Vanilla JS (ES2023+)** — модули без зависимостей
- **localStorage** — локальное хранение данных
- **Fetch API** — погода (open-meteo) и курсы валют (exchangerate-api)
- **Web Audio API** — сигнал помодоро без аудиофайлов
- **Canvas** — сжатие обоев
- **GitHub Pages** — хостинг
