## ✨ О проекте

Локальная стартовая страница на **чистом HTML, CSS и JavaScript** — без фреймворков и сборок. Единственная внешняя библиотека — крошечный [SortableJS](https://sortablejs.github.io/Sortable/) для перетаскивания. Открой `index.html` или зайди на [rakursup.github.io](https://rakursup.github.io/).

Все данные хранятся **только в твоём браузере** (localStorage) и никуда не отправляются.

Работает и на десктопе, и на планшете — перетаскивание поддерживает **мышь и тач**, совместимо со старыми браузерами.

> 🤖 Сделано в тесном сотрудничестве с [chat.qwen.ai](https://chat.qwen.ai/) — при участии моделей Qwen3.7-Max и Qwen3.8-Max-Preview.

## ✏️ Редактирование закладок

Кнопка-карандаш в шапке включает режим редактирования — рамки карточек станут пунктирными, появятся ручки перетаскивания и кнопки управления.

| Действие | Как |
|---|---|
| 🔄 Переставить категорию | Тяни за **плашку с точками** слева от заголовка |
| 🔀 Переставить ссылку | Тяни за **грип** слева от названия ссылки |
| ✏️ Переименовать категорию | Значок **✏️** в заголовке карточки |
| ➕ Добавить категорию | Кнопка **«+ Добавить категорию»** |
| 🔗 Добавить ссылку | **«+ Добавить ссылку»** внутри карточки |
| ❌ Удалить ссылку | Крестик **✕** рядом со ссылкой |
| 🗑️ Удалить категорию | Значок **🗑️** в заголовке карточки |

**Ограничения** (чтобы карточки оставались аккуратными):

- до **7 ссылок** в категории;
- название категории — до **30 символов**, ссылки — до **40**;
- слишком длинные имена обрезаются многоточием (полное имя — во всплывающей подсказке);
- ссылка длиннее **300 символов** не сохранится.

> 📌 На планшете перетаскивание запускается **долгим нажатием**, чтобы обычный свайп продолжал прокручивать страницу.

Повторный клик по карандашу выключает режим редактирования.

## 🔍 Поиск в интернете

Строка поиска в шапке поддерживает **4 поисковика** — выбери нужный в выпадающем списке слева. Выбор запоминается, результат открывается в новой вкладке.

- **Яндекс** — по умолчанию
- **Google** — классика
- **DuckDuckGo** — без слежки
- **Shodan** — поиск по IoT-устройствам (для энтузиастов)

## 🖼️ Свои обои

Фон можно заменить на любое изображение — кнопка **«Обои»** в подвале. Дашборд сам сожмёт картинку (до ширины 1920 px, JPEG) и сохранит в браузере.

> 💡 Обои хранятся локально, поэтому на другом устройстве их нужно установить заново. Слишком большие файлы (>2 МБ после сжатия) не сохранятся — место в localStorage ограничено.

## 📦 Бэкап и сброс

### Экспорт / импорт

Резервное копирование и перенос закладок между устройствами — в формате **JSON**.

- **⬇️ Экспорт** — скачает файл `dashboard-backup-YYYY-MM-DD.json` со всеми категориями.
- **⬆️ Импорт** — загрузит JSON-файл после проверки структуры.

> ⚠️ Импорт **полностью заменяет** текущие закладки. Сначала сделай экспорт, если хочешь сохранить то, что есть.

### Сброс

Кнопка **↺ Сброс** в подвале очищает все настройки и возвращает дашборд к состоянию «из коробки» — стандартные закладки, тема, обои. Действие необратимо.

## 🎨 Темы и акценты

- **Светлая / тёмная тема** — кнопка 🌙/☀️ в шапке. При первом запуске определяется по системным настройкам.
- **4 акцентных цвета** — оранжевый, розовый, синий, бирюзовый. Меняют кнопки, ссылки, заголовки и прогресс-бары. Выбор сохраняется.

## ⚡ Экономичный режим

Снижает нагрузку и расход трафика: отключает визуальные эффекты, реже обновляет данные, умно кэширует.

**Включение** — кнопка **⚡** в шапке (зелёная = активен). Состояние сохраняется между сессиями.

**Что меняется:**

- переходы и анимации становятся мгновенными, отключается blur (экономия GPU);
- данные обновляются реже, но сначала мгновенно показываются из кэша;
- при сбое радио — остановка вместо перебора станций (экономия трафика).

| Данные | Обычный режим | Экономичный |
|--------|---------------|-------------|
| Погода | 30 мин | 4 часа |
| Валюты | 1 час | 6 часов |

**Когда включать:** медленный или лимитированный интернет, ноутбук на батарее, страница открыта фоном, старое железо.

## 📁 Структура проекта

```text
├── index.html        # разметка страницы
├── style.css         # стили, темы, адаптив
├── favicon.svg       # иконка (фирменный градиент)
├── README.md         # этот файл
└── js/
    ├── utils.js        # утилиты: хранилище, защита от XSS, debounce
    ├── sortable.min.js # библиотека перетаскивания (единственная зависимость)
    ├── app.js          # ядро: закладки, темы, обои, модалки, поиск
    ├── weather.js      # погода и часы
    ├── currency.js     # курсы валют
    ├── radio.js        # онлайн-радио
    ├── notes.js        # быстрые заметки
    ├── calendar.js     # календарь
    └── pomodoro.js     # помодоро-таймер
```

> 📚 Порядок загрузки скриптов важен: `utils.js` → `sortable.min.js` → `app.js` → виджеты.

## 🛠️ Технологии

- **HTML5** — семантическая разметка, доступность (ARIA)
- **CSS3** — custom properties, grid, адаптив, светлая/тёмная тема
- **Vanilla JS** — без фреймворков и сборок
- **SortableJS** — перетаскивание (единственная внешняя библиотека)
- **localStorage** — локальное хранение данных
- **Fetch API** — погода (open-meteo) и курсы валют (exchangerate-api)
- **Web Audio API** — сигнал помодоро без аудиофайлов
- **Canvas** — сжатие обоев
- **GitHub Pages** — хостинг
